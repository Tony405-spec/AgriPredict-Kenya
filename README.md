# Agripredict Kenya

Repository for the `AgriPredict-Kenya` project.

## Overview

This project contains code, notebooks, and supporting files for analysis or machine learning workflows.

## Getting Started

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Project Structure

- `notebooks/` - exploratory analysis and experiments, when present.
- `src/` - reusable project code, when present.
- `data/` - local data files, ignored by default when present.

## Notes

Large local datasets, model artifacts, and environment files are intentionally excluded from version control.
